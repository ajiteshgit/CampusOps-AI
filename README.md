# 🎓 CampusOps-AI

**CampusOps-AI** is an autonomous multi-agent system designed to solve college administrative friction, eliminate scattered information across campus channels, and optimize student attendance management.

Built for the **Google GDG & Fetch.ai Hackathon**.

---

## 🚀 Key Features

* **Dual-Tier Attendance Calculator:** Evaluates aggregate target requirements (75%) alongside subject-specific risk zones.
* **Automated Notice Ingestion:** Unifies notices from WhatsApp, Gmail, and official college portals with SHA-256 deduplication.
* **Autonomous Administrative Execution:** Automatically generates formal leave application drafts, grade dispute letters, and custom study roadmaps.
* **Agentverse & ASI:One Compatible:** Uses the Fetch.ai `uagents` framework and Agent Chat Protocol (ACP) for decentralized discovery.

---

## 🛠️ Tech Stack

* **AI Reasoning Engine:** Google Gemini 2.5 Flash (`google-genai` Python SDK)
* **Agent Protocol:** Fetch.ai `uagents` Framework & ASI Agentverse
* **Frontend UI:** Streamlit Community Cloud
* **Environment:** Python 3.10+
